CMOS Inverter Design Using Tanner EDA

Overview:
This project demonstrates the design and simulation of a CMOS inverter using Tanner EDA.

Tools Used:
- Tanner EDA
- S-Edit
- T-Spice
- W-Edit

Design:
The CMOS inverter is designed using:
- PMOS transistor
- NMOS transistor
- CMOS technology

Simulation:
The circuit was simulated to verify the inverter operation and observe the relationship between input and output signals.

Project Files:
This repository contains the Tanner design files, simulation files, layout-related files, screenshots, and supporting documentation.

Objective:
To understand the design, simulation, and basic analysis of a CMOS inverter using Tanner EDA.

Technology:
180 nm CMOS Technology
